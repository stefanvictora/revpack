# Published Agent Output Carries Generation Attribution

Revpack records optional per-item Generation Attribution on Reply and Finding drafts as `generation.model`, with generated Agent Instructions requesting the exact runtime model name and forbidding guesses. Publish renders this metadata centrally rather than trusting draft bodies: model-bearing Agent Output receives `AI-generated via revpack · Model: …`, legacy or invalid metadata falls back to generic AI attribution, Review Notes retain the generic AI footer without new metadata, and manually supplied reply bodies receive `Published via revpack`. Guided Publish exposes the resulting attribution and fallback warning before publication, while model names remain free-form but bounded, single-line, normalized, and escaped. Attribution remains attached when a person edits a draft, but this first version intentionally adds no harness name, configuration switch, or durable model field to published-action history.
